# G-CHAM 保健師事業評価ナビ

公的資料に基づく評価指標例を、行政保健師が検索し、担当事業の評価計画に整理するための静的Webアプリです。

## 主な機能

- 17領域・4評価区分の68例を、キーワード・領域・評価区分で検索
- 指標例ごとに、原典の該当箇所と公的資料へのリンクを表示
- 選んだ指標例に、対象・期間、指標の定義、分子・分母、データ源・評価時期を追記
- 作成中の評価案をブラウザーに保存し、CSVで書き出し
- PC・タブレット・スマートフォンで使えるレスポンシブ表示

## 起動方法

`index.html` をブラウザーで開くと利用できます。ローカルサーバーを使う場合は、リポジトリのルートで次を実行します。

```bash
python -m http.server 8000
```

その後、`http://localhost:8000` を開きます。

## 評価例と出典

評価例の領域・4区分・指標記述は、行政保健師向け研修資料に整理した内容を初期データとして収載しています。各例には参照資料番号と該当ページを付け、資料詳細から公的機関の原典を開けるようにしています。

原典がストラクチャー・プロセス・アウトカムの3区分や独自の分類を用いる場合、本サイトでは指標の意味に沿って4区分へ再配置することがあります。原典に直接記載されていない補完例は、原典の指標と区別して扱います。掲載内容は全公的指標の網羅一覧ではありません。自治体の計画・事業目的・データ定義に合わせて確認してください。

## 個人情報について

評価案の入力内容は、ブラウザーの `localStorage` に保存されます。サーバーには送信されません。個人を特定できる情報や実際の対象者データは入力しないでください。ブラウザーの保存データを消去すると、評価案も削除されます。

## デザインとフォント

画面は、デジタル庁デザインシステムが示す情報の見つけやすさ、一貫したコンポーネント、アクセシビリティの考え方を参考にしています。デジタル庁の公式サービスではありません。

日本語フォントはBIZ UDPゴシック（CSS名 `BIZ UDPGothic`）を優先し、Google Fontsから読み込みます。ネットワークから取得できない場合は、端末にある日本語サンセリフ体を使います。

## GitHub Pagesで公開する場合

GitHubのリポジトリ設定で、Pagesの公開元に `main` ブランチと `/ (root)` を指定します。このリポジトリはビルド手順を必要としない静的サイトです。
